此为Windows版本安装

下载

打开github地址
选择 nvm-noinstall.zip 版本下载

文件下载后，解压放在指定目录下

配置环境变量

NVM_HOME：指向 nvm 程序本身的安装目录（比如 D:\services\nvm-noinstall）

NVM_SYMLINK：它的值是一个完全空白的文件夹路径（比如 D:\services\nvm-noinstall\symlink），
这个文件夹会在你第一次安装 Node.js 版本时由 nvm 自动创建并维护。千万不要提前手动创建这个文件夹。

将这两个环境变量都会被添加到系统的 Path 中，通常是
%NVM_HOME%
%NVM_SYMLINK%
这样系统才能在任何目录下找到 nvm 和当前激活的 Node.js。

在cmd输入 “nvm version” 显示出版本号 则为安装成功。

设置镜像源

安装Node.js

查看所有可安装的版本： nvm list available
查看所有已安装的版本： nvm list
查看当前正在使用的版本： node -v

在线安装

在线安装指定版本 22.22.2

离线安装

如网络下载慢可离线安装
在能联网的电脑上，打开 Node.js 官方下载页：https://nodejs.org/dist/, 找到指定版本，
如：Node.js 12.0.0 版本，找到 v12.0.0/ 目录，下载 node-v12.0.0-win-x64.zip 文件。

把 zip 包解压，修改文件夹名称：v12.0.0，然后放到根目录（D:\services\nvm-noinstall）下。

在cmd界面输入命令：nvm list

使用版本

输入对应的版本号
