此为Windows版本安装

下载

打开github地址 ，选择 master.zip 版本下载

安装

  1. 将master.zip 文件并解压，把解压出来的 pyenv-win 文件夹里的所有内容，都移动到安装根目录下（如：D:\services\pyenv）
    解压内容：

    复制到 D:\services\pyenv 目录下的内容

配置环境变量

安装Python

查看可用的 Python 版本：pyenv install –list
只查看 3.11 系列的版本：pyenv install –list | findstr 3.11

安装指定版本：pyenv install 3.11.7
使用版本：pyenv global 3.11.7
验证版本：python –version

查看已安装的版本：pyenv versions

备注：可离线安装
访问 Python 官方地址：打开 https://www.python.org/ftp/python/
下载 python-3.11.7-amd64.exe 文件：https://www.python.org/ftp/python/3.11.7/python-3.11.7-amd64.exe
注意：请确保下载的版本号（3.11.7）与即将执行的 pyenv install 命令中的版本号完全一致

下载 python-3.11.7-amd64.exe 文件，将下载好的文件，复制到 pyenv 的缓存文件夹（install_cache）中。如果该文件夹不存在，需要手动创建，
缓存目录：D:\services\pyenv\install_cache\
安装命令：pyenv install 3.11.7，pyenv 检测到缓存目录中有对应的安装包后，会直接使用它进行安装，不会再尝试联网下载。
安装完成后，就可以像往常一样进行验证和切换了：
pyenv versions
pyenv global 3.11.7
python –version
